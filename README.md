# Bassendean Family Practice — Redesign Demo

Modern React demo of [bassprac.com.au](https://www.bassprac.com.au/), built as a preview before the WordPress rebuild.

The demo keeps the live site’s copy, photography, logo, AGPAL badge and colour palette (navy `#0a3380`, blue `#2ea6f7`, orange `#ff9e21`, teal `#54ced4`) and uses **Montserrat** throughout.

```bash
npm install
npm run dev
```

Forms are visual only and do not submit to the clinic.
